# my-project

CyberGlitch 
Learn. Investigate. Stay Safe Online.

CyberGlitch is an educational website designed to teach children and young people about cybersecurity and online safety through interactive learning, cyber safety tips, and detective-style quiz challenges.

The project was created as part of an HTML and CSS Bootcamp and aims to help users recognise online threats, protect personal information, and develop good cyber habits.

Project Overview

CyberGlitch provides visitors with:

Cyber safety tips
Interactive detective missions
Examples of common online threats
Cybersecurity awareness resources
A contact page for feedback and questions

The website uses only HTML and CSS to create a simple, accessible, and engaging learning experience.
